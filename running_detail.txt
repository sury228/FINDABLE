# 🏗️ FINDABLE: Zero Se Lekar Abhi Tak Kya-Kya Bana Aur Kaise Kaam Kar Raha Hai

---

## 1. Asli Problem (Jo Hum Solve Kar Rahe Hain)
* **Beauty Industry ka sabse bada dard:** 30% se zyada online cosmetics (foundation, concealer) return ho jate hain kyunki ghar aane ke baad pata chalta hai shade match nahi hua.
* **Kyun hota hai?** "Toffee", "Almond", "Mocha", "Warm Sand" — yeh sirf commercial marketing naam hain. Ek brand ka "Toffee" dusre brand ke "Toffee" se bilkul alag hota hai.
* **Future Problem (AI Agents):** Kal jab AI Shopping Agents (Claude, ChatGPT, Siri) hamare liye shopping karenge, toh unhe text names samajh nahi aayenge — unhe physical, mathematical data chahiye.
* **Hamara Solution:** Findable — phone ki swatch photo se physical CIELAB color numbers nikalta hai, uska ek tamper-proof Shade Passport banata hai, aur AI agent ko PayPal ke zariye secure autonomous shopping karwata hai.

## 3. Ek-Ek Module Ki Detail (Under the Hood Kya Implement Hua)

### 🔬 A. Color Science Engine (`app/color/`)
* **`pipeline.py`**:
  * **sRGB $\leftrightarrow$ Linear RGB:** Phone cameras nonlinear sRGB me shoot karti hain; pipeline ise linear optical power me convert karti hai.
  * **von Kries White Balance:** White paper reference sheet se camera lighting (yellow bulb, shadow, sunlight) cancel karti hai taaki standard D65 daylight values milein.
  * **`rgb_to_lab()` & `lab_to_hex()`:** Real mathematical color space translation.
  * **`delta_e(lab1, lab2)`:** International standard CIEDE2000 formula. Yeh Euclidean distance se 10x better hai kyunki yeh human eye ke perception ko replicate karta hai:
    * $\Delta E \le 2.0 \rightarrow$ Human eye differentiate nahi kar sakti (**Exact Match**).
    * $2.0 < \Delta E \le 4.0 \rightarrow$ Pehanne layak match (**Close Wearable Match**).
    * $\Delta E > 4.0 \rightarrow$ Visibly different shade.
* **`metrics.py`**:
  * **ITA° (Individual Typology Angle):** $\text{ITA} = \arctan((L^* - 50) / b^*) \times (180 / \pi)$ se skin depth classify hoti hai (Very Light, Light, Medium, Tan, Deep, Rich).
  * **Hue Angle:** Undertone nikalta hai (Warm, Neutral, Cool).

### 🛂 B. Cryptographic Shade Passports (`app/passport.py`)
* Har measured shade ko ek canonical JSON banaya jata hai:
  * Measured $L^*, a^*, b^*$ coordinates
  * Measurement confidence score (0-100)
  * Method metadata
* **Tamper-Proofing:** Is JSON ka SHA-256 canonical hash banta hai aur brand ke secret key se HMAC-SHA256 se sign hota hai.
* Agar koi seller database ya API me color value badal dega, toh signature invalid ho jayegi! AI Agent hamesha cryptographically verified shade hi khareedta hai.

### 🛍️ C. Seller Studio (`app/templates/studio.html` & `app/static/js/studio.js`)
* **Clean Native Upload:** HTML `<label for="studioFileInput">` use karke lag-free file picker banaya jo bina double-click bug ke turant photo kholta hai.
* **Instant Pixel Extraction:** Image load hote hi center swatch area se real RGB sample hota hai aur backend ko jata hai.
* **Transient Query Cache (`QUERY_REFERENCE_CACHE`):**
  * User ka uploaded swatch database catalog shades me add NAHI hota (taaki catalog pollute na ho).
  * Sirf temporary cache me rehta hai aur ek code banta hai (e.g. `REF-A9B2`).
* **Instant Action:** Turant button active hota hai: `🤖 Send to AI Agent & Find Match (REF-A9B2) →`.
* **Benchmark Grid:** Niche AG Grid me Priya's Clean Beauty ke 12 unalterable physical shades benchmark ki tarah dikhte hain.

### 🤖 D. AI Shopping Agent & MCP Server (`app/llm/` & `app/mcp_server.py`)
* **FastMCP Server:** 6 standard tools expose karta hai:
  1. `match_shade_tool(reference) \rightarrow` CIEDE2000 match
  2. `search_products_tool(category, max_price) \rightarrow` Catalog filter
  3. `get_shade_passport_tool(shade_id) \rightarrow` Passport verification
  4. `create_checkout_tool(items) \rightarrow` PayPal order creation
  5. `get_order_status_tool(order_id) \rightarrow` Live tracking
  6. `open_shade_promise_tool(order_id, ref_code) \rightarrow` Auto refund
* **Auto-Execution on Landing:** Studio se aane par agent chat `?ref=...` URL parameter padh kar turant query run kar deta hai.
* **Direct Camera Upload (📷):** Agent chat bar me bane camera icon se bhi direct photo pick karke turant CIELAB match ho jata hai.
* **Live Telemetry Drawer:** "⚙️ Behind the Scenes" panel me real-time MCP tool invocations stream hoti hain.

### 💳 E. PayPal Deep Integration (`app/paypal/` & `app/services.py`)
* **PayPal Orders v2 API:**
  * AI agent credit card nahi maangta. Woh backend se server-authoritative pricing ke sath secure `approve_url` nikalta hai.
  * Buyer PayPal Sandbox popup me jaakar safe 1-click approval deta hai.
* **PayPal Webhooks:**
  * Incoming webhook signature verification (`PAYMENT.CAPTURE.COMPLETED`).
  * Live orders Seller Dashboard me stream hote hain.
* **Killer Feature — "Shade Promise" (Payments v2 Refund API):**
  * Agar customer ko deliver hone ke baad lagta hai shade alag hai, toh dispute open hota hai.
  * System physical $\Delta E$ re-measure karta hai. Agar $\Delta E > 2.5$ nikla, toh system automatically bina human intervention ke PayPal Refund API call karke instant refund issue kar deta hai!

## 4. End-to-End Pura Flow Kaise Jurta Hai (Live Workflow)

```
[1. SELLER STUDIO / CONSUMER UPLOAD]
   User swatch photo upload karta hai (/studio)
   └── Backend skimage/numpy real CIELAB nikalta hai: L* 62.4, a* 13.9, b* 24.1
   └── Query Code banta hai: REF-A9B2 (In-memory cached)
   └── User clicks: [🤖 Send to AI Agent & Find Match →]

[2. AI AGENT REASONING]
   Page khulta hai: /agent?ref=REF-A9B2
   └── Agent tool call karta hai: match_shade(reference='REF-A9B2')
   └── CIEDE2000 algorithm database ke 12 shades se comparison karta hai
   └── Result category decide hoti hai:
       ├── ΔE ≤ 2.0  → "✅ Exact Match Found: Honey 04 (ΔE 1.2)"
       ├── ΔE ≤ 4.0  → "🔍 Close Match Found (Wearable tone variance)"
       └── ΔE > 4.0  → "❌ Exact Match Not in Catalog (Showing nearest candidate)"

[3. AUTONOMOUS CHECKOUT]
   User "Order Shade" ya "buy shd_honey04" dabata hai
   └── Agent tool call karta hai: create_checkout(shade_id='shd_honey04')
   └── PayPal Orders v2 API secure Order banata hai ($28.00 USD)
   └── Agent card me display karta hai: [Approve in PayPal Sandbox →]

[4. CAPTURE & SELLER DASHBOARD]
   User PayPal me approval deta hai
   └── Order status: CREATED → COMPLETED
   └── PayPal Webhook trigger hota hai
   └── /dashboard par AG Grid me live order aur cryptographic passport hash stream ho jata hai

[5. POST-PURCHASE SHADE PROMISE]
   Delivered product me difference laga?
   └── /promise/{order_id} par dispute open hota hai
   └── System ΔE check karta hai: agar ΔE > 2.5 → Instant PayPal Refund!
```
